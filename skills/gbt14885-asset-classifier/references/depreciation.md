# 固定资产折旧

财政部[《政府会计准则第3号 - 固定资产》应用指南，财会〔2017〕4号](https://www.mof.gov.cn/zcsjtsgb/gfxwj/201702/t20170221_3583491.htm)表1是政府固定资产折旧年限的依据。使用时核对最新适用规定与单位、主管部门细化口径；表中的“不低于”是最低年限，不是自动确定的实际年限。准确分类、单位确认的具体年限及其合理性均需核实。用户确认某批统一年限只适用于该批，不作为其他任务默认值。

常见参考类别：计算机设备、办公设备不低于6年；电气设备、广播电视电影设备不低于5年；家具不低于15年，用具、装具不低于5年。完整类别和其他条件以财政部原文表1为准，不以这些示例替代表1，也不要机械地把新国标分类与旧表类别等同。对照表1的类别、依据和单位年限，分类不明确、确认年限低于适用最低值或超过规定区间时，列出差异并向用户核实，不得以用户给出的统一年限掩盖冲突。

指南规定按月计提，当月增加的资产当月开始计提。实际确定新增或交付月份、导入截止月份、财务账已提月数与累计金额，不能单凭取得日期或记账日期推断。日期、具体年限、方法或账务数据不明时先向用户确认，未确认字段留空；有财务账数据时以核对一致的实际数据为准。注意改建、已折旧及其他例外按适用规定处理。

新录入资产可根据用户确认的本批录入口径填写已提月数；确认截至录入基准日确无已计提折旧时，月数填0、累计额填0.00。新录入不必然代表从未计提，若财务账已有折旧或截止时间不明确，应核对后填写，不自动推断为0。

年限平均法测算时，使用单位确认的月数、原值及适用的残值政策；政府会计主体按准则计提时不考虑预计净残值。以十进制计算，保留分、说明月度及累计四舍五入方式，已提月数不能超过年限，累计折旧不超过应计提总额。计算结果应与财务账核对，不能将估算冒充已入账数字。按模板保留金额两位小数。

## 计算与核对步骤

1. 区分取得日期、实际投入使用日期、固定资产确认日期、记账日期以及折旧数据截止月份。按模板定义填写；取证包括验收、交接、安装及凭证。取得或记账日期不同并不自动改变折旧起算月。需要安装的资产通常在安装完成交付使用时确认，不需安装的资产通常在验收合格时确认；具体依据见[固定资产准则](https://www.mof.gov.cn/gp/xxgkml/hjs/201607/P020160714547405846932.pdf)。系统自动起算规则未核实时不要臆测。
2. 确认该资产适用固定资产折旧而非无形资产摊销，并识别不计折旧和特殊处理情形；暂估入账资产也按适用规定计提。若取得日至确认、记账跨月或跨年，提示核查确认和账卡是否及时一致，不凭间隔断定错误。
3. 按实际资产分类和适用规定确定可用年限，说明最低值或区间不是单位已经选定的值。单位给出年限后换算为整数月，例如6年为72个月、15年为180个月。用户的批次统一值需要逐类核对，不能对不适用类别自动套用。
4. 确认新增或交付确认月份、截止月份及财务账实际已提月数。按指南规则估算时，截止月份包含在内：例如确认月份为2026-09，截止2026-10，则为2个月；若确认月份为2026-10，则为1个月。计算月数限制为0到年限月数，截止早于确认月份标记未开始，不能倒算负数。财务账及系统导入基准另有口径时先解释差异，不覆盖账面数据。
5. 年限平均法参考测算：月折旧 = 原值 ÷ 年限月数；累计测算 = 按单位或系统确定的分位舍入规则计算，并以应折旧总额为上限。每月先四舍五入再累计与累计后四舍五入可能差1分或更多，不得随意二选一作为实际账面金额；末月通常需处理舍入尾差，具体以单位系统和账务规则为准。例如原值100元、年限72个月、已提10个月：每月舍入为1.39元，合计13.90元；精确累计后再舍入为13.89元。0个月对应累计0.00元。
6. 对每条记录核对年限为正整数、已提月数为不大于年限的非负整数、累计折旧不为负且不超原值。校验计提状态、方法、年限、月数、金额的一致性，金额保留数值并显示两位小数；存在财务账时逐项核对并记录差异。财务账未确认前，明确标记测算结果，不作为正式已计提金额导入。
