# 资产分类与批量填报

将原始资产台账转为有依据、可追溯的分类结果。国家标准分类、上海系统可选代码和导入模板是不同资料，不能假设它们相同。具体资料、校验及交付要求见 [references/workflow.md](references/workflow.md)。

需要确定折旧年限或计算累计折旧时，阅读 [references/depreciation.md](references/depreciation.md)。

1. 明确用户要求的结果及输入：资产台账、GB/T 14885-2022 可检索字典或标准原文、上海系统当前代码字典、系统实际导入模板及填写说明。先检查现有文件和系统导出信息。记录来源、版本、获取日期和适用范围。
2. 检查每份表的工作表、表头、实际行、代码数据类型、合并单元格和公式。识别字段和数据起始行，保留原始文件。对字典进行完整性、重复代码、代码名称冲突、层级及版本检查；检查方式依实际字典结构和标准规则确定，不能用推测的编码长度或前缀宣称通过。将国家字典与标准原文核对，并如实说明核对范围。
3. 逐项结合名称、用途、规格、型号及已有资料识别资产，查找字典中有证据的候选项；将标准代码和名称、匹配依据及来源记录到审核结果。分类有多个合理候选时，在执行过程中向用户列出选项并等待选择；无法区分时说明缺少的信息。不要以品牌或型号推断未提供的功能，不要编造代码、分类名称或映射。
4. 根据上海系统当前字典逐项验证可选状态、层级和适用条件。用户确认采用国标时，可用国家字典分类；检查实际模板是否内置系统字典，以对应表单的数据验证范围为准，保留系统要求的完整代码和名称。仅在有可靠依据时填入系统代码；国家代码相同不代表系统接受。未取得系统字典或存在冲突时，将系统代码留空并标记待核实。缺失标准字典时不要声称完成国家标准分类。
5. 生成独立的审核 Excel，保留每条原始记录及可追溯的源工作表和行号，区分已确认、待人工确认和资料不足。逐项列出分类依据、国家及系统代码、核对状态和问题。已确认只表示依据足够且完成适用的核验，不能代替用户或单位审批。
6. 执行过程中主动收集所有缺失的必填及条件必填信息，分组询问共同字段，有模板选项时列出供用户选择；收到回复后继续填写和检查，不把未完成草稿作为最终结果。用户无法提供或要求暂停时，可交付清楚标记缺项和不可导入状态的草稿。仅把完成必要核验、符合模板必填条件的记录纳入最终导入文件，其他记录另列原因和数量。保留模板和源表，复核行数、字段、代码文本和汇总金额；实际导入未验证时不得宣称系统已接受。

实际向系统上传、保存、提交或批量写入，只在用户明确要求且完成必要核验后进行；遵守系统界面和授权要求。导出或准备文件不等于已导入成功。
